# Commercial document set

**DRAFT — NOT FOR SIGNATURE — NOT LEGAL ADVICE**

These English-language templates are negotiation checklists, not final
agreements. They intentionally leave party names, prices, scope, governing law,
tax, dispute resolution, liability caps, data obligations, and other deal terms
open. Before use, a qualified Chinese intellectual-property lawyer should adapt
the selected documents to the parties, transaction, institutional restrictions,
and applicable law.

| Document | Intended use |
| --- | --- |
| `COMMERCIAL_LICENSE_AGREEMENT_DRAFT.md` | Non-exclusive rights for a defined version/product; optional controlled source access |
| `PROFESSIONAL_SERVICES_SOW_TEMPLATE.md` | PoC, integration, validation, deployment, and maintenance services |
| `DEVELOPMENT_SPONSORSHIP_AGREEMENT_DRAFT.md` | Roadmap support without platform ownership or default exclusivity |
| `INDIVIDUAL_CLA_DRAFT.md` | Individual contributor retains copyright and grants broad copyright/patent licenses |
| `CORPORATE_CLA_DRAFT.md` | Company authorizes employee contributions and grants broad copyright/patent licenses |

The commercial license and SOW should normally be separate signed documents or
clearly separated schedules with separate fees. A sponsorship with defined
deliverables, milestones, acceptance, or consideration should be treated as a
paid development/services arrangement to the relevant extent.
